# Picker

> Picker (Picker Express) is a Latin American last-mile delivery orchestration platform connecting e-commerce and retail businesses with 200,000+ couriers across 10+ delivery companies. It exposes a REST API and e-commerce plugins for creating bookings, quoting delivery costs, tracking shipments, and subscribing to delivery lifecycle webhooks. Operates in Mexico, Ecuador, Colombia, Peru, Chile, Uruguay, and Costa Rica. Backed by 500 Global.

## APIs
- [Picker API (Swagger 2.0, 413 operations)](https://api.pickerexpress.com/swagger.json): Bookings, pre-checkout quoting, tracking, cancellations, drivers, businesses, accounting, and e-commerce integrations (VTEX, Shopify, Spoonity, Datil).
- Host: https://api.pickerexpress.com (test: https://dev-api.pickerexpress.com)
- Auth: API Key in the `authorization` header (from the Picker Dashboard; Pro Plan required)
